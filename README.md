# Dynamic Gallery Frontend with Vanilla JavaScript

This repository contains my frontend implementation for a dynamic gallery portfolio using Vanilla JavaScript. 
The backend was provided and is based on the original repository. 

## My Contribution
- Full frontend integration (HTML & CSS) from a Figma design.
- Developed dynamic frontend interactions (display, add, delete images).
- Implemented user authentication and gallery filters.

## Technologies Used
- HTML / CSS
- JavaScript
- Fetch API

## Features
- Display images fetched from backend.
- Modal windows for adding/deleting images.
- User authentication handling.
- Gallery filtering.

## What I Learned
- Manipulating the DOM using Vanilla JavaScript.
- Managing complex layouts with modals.
- Reading and understanding API documentation using Swagger/Postman.
- Performing CRUD operations from the frontend using Fetch API.
- Implementing frontend user authentication logic.
